# 🛰️ Lidar–Lidar and Lidar–Camera Calibration Package

This package is used to perform **Lidar–Lidar** and **Lidar–Camera** calibration.  
It supports multiple lidars and stereo cameras, synchronizing the data into a unified ROS bag for further processing.

---

## 📥 Inputs

- **Camera Images**
  - Right and Left camera image streams.

- **Lidar Data**
  - Single lidar point cloud.
  - If multiple lidars are used, transform all lidar point clouds into one fixed frame.  
    *(Example: In our setup, we used two lidars — left and right. The left lidar point cloud was transformed into the right lidar frame and merged, resulting in a single merged point cloud.)*

---

## 📤 Output

- **Synchronized lidar point cloud** and **camera image data**, stored in a **ROS bag file**.

---

## ⚙️ How to Run

### 1. Launch Lidars
Ensure all lidars are powered on and properly connected.  
If needed, ping each lidar from the host computer to verify communication.

```bash
roslaunch ouster_ros two_lidar_driver.launch


## 🚀 Launch Cameras

Ensure both cameras are connected and turned on.  
You can check the data stream using the `rqt_image_view` plugin.

```bash
roslaunch ids_multi_cam camera_launch.launch


## 🔧 Multiple Lidar Calibration

Make sure the estimates provided are correct — failing to do so may result in **false convergence**.

```bash
roslaunch multi_lidar_calibrator multi_lidar_calibrator.launch \
  points_parent_src:=/ouster1/points \
  points_child_src:=/ouster2/points \
  x:=0.0 y:=3.0 z:=0.0 roll:=0.0 pitch:=0.0 yaw:=0.0


## 🌐 Merge Lidar Point Clouds

Merge the lidar point clouds into a single fixed frame (here, the **right lidar** is chosen as the fixed frame) using the transform generated by the **Multiple Lidar Calibration** tool.

```bash
rosrun lidar_merge lidar_ros


## 💾 Synchronize and Store Data

Synchronize the lidar and camera data, and store the synchronized output into a **ROS bag**.

## 🧩 Important Points to Consider When Performing Lidar–Camera Calibration

1. **Checkerboard Visibility:**  
   Ensure the **edges and corners** of the checkerboard are clearly visible in the lidar point cloud.  
   *(If possible, position yourself so that your head and body do not overlap with the point cloud. **Make sure your head and body is behind the checkerboard** )*

2. **Pose Variation:**  
   **Rotate the checkerboard laterally** to introduce skew in the point cloud, and capture data from **different distances and angles**.  
   This helps estimate calibration parameters more accurately.

3. **Avoid Body Proximity:**  
   Do not hold the checkerboard close to your body — extend your arm away to prevent occlusion.

4. **Dual Sensor Visibility:**  
   Ensure the checkerboard is **clearly visible** in both the **camera** and **lidar** views.

5. **Orientation:**  
   Always keep the checkerboard at approximately **45° longitudinally**, so that all corners are properly visible in the lidar point cloud.
